# Upgrade Calcit 0.13.64 / 升级 Calcit 0.13.64

## 中文

- 将 Calcit CLI 与 @calcit/procs 从 0.13.32 同步升级到精确版本 0.13.64。
- 对齐 Respo 0.16.87、Reel 0.6.10 与 Respo UI 0.7.13 的稳定 tag。
- 使用 strict Caps 与 toolchain verification 阻断依赖选择告警和 JS runtime 版本漂移。
- 取消 .gitignore 对 calcit.cirru 的隐藏，后续 canonical Snapshot 修改必须可见。
- 文档直接介绍 Calcit 的 JS backend 与当前 workflow，不再以 calcit-js 历史命名作为主叙述。
- 将 updater 的 tag-match 迁移为 match，并把 Option unwrap/unwrap-or 调整为方法调用，作为新项目模板示例。
- 增加 native v2 quality baseline 与 dynamic-methods 0 门禁，阻止存量 schema/FFI 边界债务增长。
- 将 README format/check-md 加入模板 CI，保持面向 calcit docs 的示例可验证。

## English

- Upgrade the Calcit CLI and @calcit/procs together from 0.13.32 to the exact 0.13.64 release.
- Align the stable Respo 0.16.87, Reel 0.6.10, and Respo UI 0.7.13 tags.
- Use strict Caps and toolchain verification to reject dependency-selection warnings and JavaScript runtime version drift.
- Stop hiding calcit.cirru in .gitignore so future canonical Snapshot changes remain visible.
- Describe Calcit's JavaScript backend and the current workflow directly instead of centering the historical calcit-js name.
- Migrate updater tag-match to match and express Option unwrap/unwrap-or as methods so new projects start from the current API style.
- Add a native v2 quality baseline and a zero dynamic-method gate so existing schema/FFI boundary debt cannot grow.
- Add README format/check-md validation to the template CI so examples remain compatible with calcit docs.
